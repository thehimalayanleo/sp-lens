Then we looked inside its middle layers for that word.

Method

Four readouts, one cleaned list

Every lens asks the same question: if we stopped the model at this layer, which words is it leaning toward? Each one answers with a different trick and sees a different part of the picture. SP-Lens asks all four, removes the noise each one adds, and fuses what is left.

1.0

R-lensLike the J-lens, but it changes only the backward rules of RMSNorm and the gated MLP, so the transport follows the model's own nonlinearities. The forward pass is unchanged; splens fit checks this.

The strongest single source. Needs a fitted transport.

0.5

Earlier positions

The logit lens at earlier tokens of the prompt, max-pooled. Concepts often form before the last token.

0.25

J-lensJacobian lens: carry a layer's hidden state to the output through the average Jacobian of the layers above it, fitted once per model on 25 short prompts.

Transport through the model's downstream Jacobian.

0.25

Logit lens

Decode the layer directly with the output head.

How the lists are cleaned

Each list is PMI-correctedPointwise mutual information: subtract how often a token shows up for ordinary calibration text, so tokens that appear for every input (junk like "fdb" or a stray comma) drop out. against calibration text, deduplicated by surface form, and stripped of tokens that are already in the prompt. The four lists are then fused, each token scored as weight ÷ rank, with a penalty of 0.35 for each earlier layer that already showed it (capped at 3), so new ideas rise above ones that are only repeated.

How the numbers were kept honest

All settings (the weights above, the PMI strength, the novelty penalty) were fixed on a development split. We then measured once on a held-out confirmation split of 421 prompts in six categories: association, multi-hop, multilingual, order of operations, poetry and typos. A prompt counts as found when the labelled concept is in the lens's top 10 at some layer. That is simpler than the benchmark's pass@10 metric.

What it does not do
  • SP-Lens still uses the J-lens and R-lens to propose candidates, so it does not replace them.
  • It does not win at every layer.
  • Poetry planning (the rhyme a model plans ahead) stays near zero for every lens, SP-Lens included.
  • An agreement-gated variant replicated on Qwen 27B models, but tied on SmolLM2-1.7B and OLMo2-1B.
  • The library agrees with the research harness on about 91% of displayed tokens across hardware. It is the same algorithm, close numerically, but not bit-identical (parity notes).

Use it

Read your own model

Works with decoder-only models in the Llama, Qwen, SmolLM and OLMo families, and looped models such as Ouro. Without fitted lenses, SP-Lens falls back to the logit lens plus earlier positions, which needs no fitting.

# install
pip install git+https://github.com/thehimalayanleo/sp-lens

# fit the J and R transports once per model (GPU above ~1B parameters)
splens fit HuggingFaceTB/SmolLM3-3B --out lenses/smollm3

# read a prompt, layer by layer
splens read HuggingFaceTB/SmolLM3-3B \
  "The capital of the country where the Eiffel Tower stands is" \
  --lens-dir lenses/smollm3 --compare logit j r
from splens import SPLens, load_model

model, tok = load_model("HuggingFaceTB/SmolLM3-3B")
lens = SPLens(model, tok, "lenses/smollm3")
lens.calibrate()                     # PMI baselines from calibration text
reading = lens.read("Fact: the currency of Japan is")
print(reading.table())               # SP-Lens top 10 per layer
