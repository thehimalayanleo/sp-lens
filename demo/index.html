SP-Lens Keywords

Before a language model writes its next word, its middle layers often hold a concept it never says: the country in a two-step question, the correct spelling behind a typo. A lens reads those layers as words. SP-Lens combines the J-lens with the R-lens, the logit lens and earlier token positions, then cleans the list. How to read this

Keywords come from the per-layer lists of each lens. Only word-like tokens count, and a token that shows up in the lists of 5% or more of all prompts is dropped as background noise. Each token scores 1/rank × log(prompts ÷ prompts containing it), summed over layers. The small number is how many layers it appeared in. This step is for display. It never sees the labels, and it runs the same way for every lens. On the looped Ouro models a layer reads as loop step.layer.

Highlighted words match a labelled intermediate concept for that prompt. Grey tokens in the layer table are not word-like.

The numbers come from the confirmation split, using the lens settings fixed in the SPLENS-V4 development round. The bar chart counts a prompt as found when any layer's list contains the concept. That is a simpler summary than the benchmark's pass@10 metric. The keyword hit rates (, SP-Lens ) are a post hoc look and not a benchmark result.
